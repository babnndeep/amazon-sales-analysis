An interactive **Amazon Sales Analysis Dashboard** built using Python, Pandas, Plotly, and Streamlit.

This project analyzes Amazon sales data and presents meaningful insights through interactive charts, visualizations, and dashboard components.

---

## 🚀 Project Overview

The Amazon Sales Analysis Dashboard helps analyze sales performance and understand important business metrics from Amazon sales data.

The dashboard provides an interactive way to explore the dataset and identify patterns and trends in sales.

### Key Objectives

- Analyze Amazon sales data
- Understand sales trends
- Explore product and order information
- Visualize important sales metrics
- Identify patterns in the dataset
- Provide an interactive dashboard for analysis

---

## 🛠️ Technologies Used

- **Python**
- **Pandas** – Data cleaning and analysis
- **NumPy** – Numerical operations
- **Plotly** – Interactive visualizations
- **Streamlit** – Interactive web dashboard
- **Jupyter Notebook** – Data exploration and analysis
